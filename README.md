# 3W Mini Social Post Application

A full-stack social feed application built as part of the **3W Full Stack Internship Assignment**.  
The project demonstrates core social networking features with a clean UI and scalable architecture.

---

## 🚀 Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  

---

## ✨ Features
- User authentication (signup & login)
- Public social feed (accessible to guests)
- Create posts with text and/or image
- Like and comment on posts
- Role-aware UI interactions (guest vs logged-in users)
- Responsive and clean layout inspired by TaskPlanet

---

## 📁 Project Structure
- `frontend/` → React frontend  
- `backend/` → Node.js + Express backend  

---

## 🔧 Post-Deployment Improvements Planned
- Normalize post owner data using populated user references
- Enforce strict server-side authorization for edit/delete actions
- Add edit and report post flows
- UI polish and performance optimizations
